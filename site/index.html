How well do AI coding tools actually handle Arabic?

Mizan (Arabic ميزان — "the scale") weighs Cursor, Claude, Copilot, v0 and Lovable on right-to-left / Arabic UI. Everyone measures speed and correctness in English; nobody measures whether the AI-built web works for a fifth of the planet. The "RTL" academic name-collision (hardware register-transfer-level) leaves the right-to-left correctness space unclaimed — Mizan claims it.

Scores are computed by node score.js from real tool outputs under outputs/. Higher is better. Want your tool scored (or want to help)? Run the 15 prompts and open a PR.

Method

  1. Give each tool the same 15 Arabic/RTL prompts (prompts.md).
  2. Save its output under outputs/<tool>/; grade it: node score.js outputs
  3. The graders are miraat + kashida + daleel (the Otto RTL toolchain) — objective, reproducible.
  4. Scoring is gated (no Arabic → 0, so a tool can't win by shipping empty code), per-prompt normalized, and clamped. Full methodology in the README.
