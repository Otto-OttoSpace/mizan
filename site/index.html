Mizan · ميزان

An open benchmark for right-to-left correctness in code

Mizan (Arabic ميزان — "the scale") weighs how well code handles right-to-left / Arabic UI. Everyone measures speed and correctness in English; nobody measures whether the AI-built web works for a fifth of the planet. Mizan is an open harness: run the 15 prompts through any tool and grade the output with the Otto toolchain. The reference fixtures below self-test the graders.

Want to benchmark a real tool? Run the 15 prompts through it, save the output under outputs/<name>/, and grade it with node score.js. Results are reproducible with pinned grader versions — capture the tool version and date.

Method

  1. Give each tool the same 15 Arabic/RTL prompts (prompts.md).
  2. Save the output under outputs/<name>/; grade it: node score.js outputs
  3. The graders are miraat + kashida + daleel (the Otto RTL toolchain) — objective, reproducible.
  4. Scoring is gated (no Arabic → 0, so a tool can't win by shipping empty code), per-prompt normalized, and clamped. Full methodology in the README.
